# Exchanges Policy

## Like-for-like exchanges
Same item in a different size or colour can be exchanged within **45 days** of purchase, even if the return window has closed (except electronics, which follow the 15-day return window).

## Exchanges for a different item
Treated as a return plus a new purchase. The return policy applies to the original item. If the new item costs less, the difference is refunded to the original payment method; if more, the customer pays the difference.

## Online orders exchanged in store
Online orders can be exchanged at any NovaMart store. The associate must look up the order number; the item must be in stock at that store. If not in stock, the associate can place a ship-to-home exchange at no shipping cost.

## Defective item exchange
A defective item can be exchanged for the same model within the warranty period (see Warranty Policy). If the same model is unavailable, offer a refund or an equivalent model of equal or lower price; an upgrade requires manager approval.
